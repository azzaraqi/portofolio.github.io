## 3. Project Showcases (Portofolio Unggulan)

*   **Kategori**: Web Development (Laravel)
*   **Deskripsi**: Platform inovatif penyedia jasa homecare kesehatan terpadu. Dibangun dengan framework Laravel untuk menghadirkan sistem pemesanan yang aman, terstruktur, dan performan tinggi bagi mitra pengasuh dan pasien.
*   **Key Stack**: PHP, Laravel, MySQL, Bootstrap/Tailwind.

### 2. UI/UX Design Portfolio
*   **Kategori**: Product Design / UI & UX
*   **Deskripsi**: Koleksi konsep antarmuka pengguna digital yang modern dan berorientasi pengguna, mencakup perancangan **Pusat Informasi Publik**, sistem **Shopping Cart (E-commerce)** yang konversif, dan sistem manajemen hubungan pelanggan (**CRM**).
*   **Key Stack**: Figma, Wireframing, User Testing.

### 3. AI Indonesian Text-to-Speech (TTS)
*   **Kategori**: Artificial Intelligence / Machine Learning
*   **Deskripsi**: Aplikasi pengolah suara berbasis kecerdasan buatan untuk mengubah teks digital menjadi ucapan lisan berbahasa Indonesia dengan intonasi natural. Mengintegrasikan teknologi pembelajaran mendalam (Deep Learning XTTS) untuk hasil suara yang realistis.
*   **Key Stack**: Python, Deep Learning, Coqui TTS/XTTS, Audio Normalization.

### 4. Apl_GS (Ghost Shopper App)
*   **Kategori**: Mobile Development (Flutter)
*   **Deskripsi**: Aplikasi mobile penilaian outlet retail dan F&B yang digunakan oleh penilai independen (Mystery Shoppers). Memudahkan pencatatan audit operasional secara instan, offline caching, serta sinkronisasi aman ke cloud database.
*   **Key Stack**: Dart, Flutter, State Management, SQLite/Rest API.

### 5. Booking Camping Ground & Tenant
*   **Kategori**: Full-stack Web Development
*   **Deskripsi**: Aplikasi web reservasi akomodasi camping dan penyewaan booth tenant untuk event organizer. Menyederhanakan alur registrasi, pemilihan lahan/kaveling, serta visualisasi ketersediaan secara real-time.
*   **Key Stack**: HTML5, CSS3, JavaScript, Database Engine.
